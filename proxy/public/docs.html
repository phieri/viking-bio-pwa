Installation & support

Run your Viking Bio burner with a clean, connected dashboard

Use this guide to wire the Pico bridge, connect it to your home Wi‑Fi, and start monitoring the burner from the browser or your phone.

🔥

Live burner status

Check flame, fan speed, temperature, and error codes without leaving the dashboard.

📶

Wi‑Fi & proxy

Pico W stays connected to your network and streams signed telemetry to the proxy.

🔔

Webhook alerts

Configure a WEBHOOK_URL to receive flame, error, and seasonal cleaning reminders as JSON payloads.

01

Connect the burner to the Pico bridge

Run the burner serial output through a 5 V to 3.3 V level shifter and connect the Pico W RX pin to the burner TX line. Keep the ground common.

  • Use the burner cable labeled TX / data
  • Place the level shifter between the burner and GPIO1
  • Verify the wiring before powering the Pico
02

Configure the Wi‑Fi and proxy settings

Use the serial configuration command set or the built-in setup tool to store the Wi‑Fi SSID, password, and the address of the proxy machine.

  • Set your home SSID and password using the bridge command interface
  • Enter the proxy server address without brackets when using the USB serial command
  • Leave the default port at 9000 unless the service runs elsewhere
03

Configure the webhook endpoint

Point the proxy at your external alert endpoint and let it forward notification JSON whenever flame, error, or cleaning events occur.

  • Set WEBHOOK_URL to your receiving service
  • Verify the payload shape matches your consumer expectations
  • Use the dashboard to confirm telemetry is updating while the hook receives test events

Quick checklist

  • Burner and Pico are connected correctly
  • Wi‑Fi and proxy address are saved on the device
  • Dashboard shows live temperature and flame values
  • WEBHOOK_URL points at your external alert receiver
